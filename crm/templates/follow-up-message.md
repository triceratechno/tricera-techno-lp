# 💬 返信・フォローアップ用テンプレ集

> 顧客に合わせて必ず一語一句調整する。コピペ禁止。トリケラテクノの一人称・口調に合わせる。

## 1. 一般的な返信の構造（5部構成）

1. **共感** — 相手の状況・気持ちに触れる
2. **称賛** — できていること・成長を1点
3. **核心** — 今回の相談への回答
4. **次の一手** — 具体的に何をやるか1つ
5. **問いかけ** — 次の返信を引き出す質問

## 2. シーン別ひな型

### A. 楽曲送付への第一声
```
（曲名）聴かせていただきました🦖
（共感ポイント）が伝わってきて、（参考アーティスト）の世界観に近づいてますね。

特によかったのは（具体ポイント）。
ここから一段階上げるなら、まず（最大インパクト改善）から取り組んでみてください。

（具体的な操作 or 数値）

試した結果がどうだったか、また聴かせてもらえると次のFBが組み立てやすいです🦕
```

### B. 1曲完成おめでとう（有料化前段）
```
1曲完成おめでとうございます🎉🦖
（具体的にどこが良くなったか）が大きく伸びましたね。

チャンネルの方も活動の流れが出てきていてすごく良いと思います。

ところで、2曲目はどんな曲を作りたいですか？
方向性が見えてきたら、一緒に設計図から組み立てていけますよ🦕
```
→ 返信が来たらスタンダードコース（¥9,800）の話に自然に展開

## 3. NGパターン（やらない返信）
- 一般論だけのアドバイス（必ず数値・具体操作・参考曲を入れる）
- 「頑張ってください」だけで終わる返信
- アップセルのタイミングが早すぎる提案
- 名前の取り違え（DAn と D を間違える など）
- 約束した期日への言及なし／無断遅延
