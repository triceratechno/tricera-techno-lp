# 📈 アップセル提案テンプレ

> ⚠️ タイミングが命。`PLAYBOOK.md` の「5. アップセルの判断基準」を必ず先に確認すること。

## 1. 無料 → スタンダード（¥9,800）

**タイミング**：1曲完成 ／ 新規曲のスタート ／ 自力で詰まった瞬間

```
ここまでの伸び方を見ていて、もう一段引き上げるタイミングだと思います。
スタンダードコース（¥9,800・2週間指導／修正2回）で、（顧客の悩み）を一緒に解決しませんか？

具体的には：
- 音色差し替え
- リズム制作のサポート
- アドバイス＋修正2回

返金保証つき（納品48時間以内なら全額返金）なので、合わなければ抜けてもらって大丈夫です。
```

```
スタンダードでの仕上がり、すごく良くなりましたね🦖
```


## 6. 提案を入れない判断（重要）

以下の場合、**提案しない**：
- 信頼関係が浅い（接点1〜2回）
- 直近のFBに不満を持っている可能性がある
- 顧客が落ち込んでいる／詰まっている時
- 返金申請の可能性がある期間（納品48時間以内）

**価値提供を続けてタイミングを待つ。**
