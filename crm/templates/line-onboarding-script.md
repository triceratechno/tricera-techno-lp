## このオンボーディングフローのCRM活用

新規LINE顧客がテンプレ返信した時に集まる4項目：

| 項目 | CRMフィールド |
|---|---|
| ニックネーム | display_name |
| DTM歴・DAW | dtm_years / daw |
| 作りたいジャンル | genre / references |
| 今いちばん困っていること | pain_point（自由記述）／ next_action の起点 |

これだけで `customers/<id>.md` の frontmatter のほぼ全項目が埋まる設計になっている。

## 新規顧客追加の標準フロー

1. テンプレ返信を受信したら、**24時間以内**に第1回返信を送る
2. `customers/<id>.md` を作成（`templates/new-customer.md` をベースに、上記4項目で埋める）
3. ジャンル・参考曲が判明したら、その方向に特化した第1回FBを組む
4. **「Anymaの曲1つ決めて、ドロップだけ作る」** のような **小さな具体課題** を渡す
5. 詰まったタイミングでロードマップ案内＋スタンダードコース提案へ自然に接続
