# 📖 トリケラテクノ CRM 運用プレイブック

> このCRMを「滞らせない」ための運用ルール集。Claude Codeはこの規則に従って提案・返信・更新を行う。

## 1. 基本理念
- **約束は守る**（特に「週末までにFB」など期日の付いた約束）
- **混同しない**（DAnさんとDさんは別人。返信前に必ず照合）
- **記録は即時**（やり取りしたら同じセッションで該当ファイルを更新）
- **次の一手を必ず決める**（`next_action` が空欄になっている顧客はゼロにする）

## 2. ステータス定義

| ステータス | 意味 | 次に動くトリガ |
|---|---|---|
| 🔵 **無料相談中** | LINE/Discordでカジュアルに相談を受けている段階 | 信頼関係が深まった瞬間 → スタンダード提案 |
| 🔵 **無料サポート中** | 1〜数曲まで無料でFBしている段階 | 1曲完成・新規曲スタートのタイミング → スタンダード提案 |
| 🔵 **有料化タイミング** | 提案するベストタイミングが来ている | 即提案（24h以内） |
| 🟢 **成約済み** | 決済確定（Stripe入金確認 含む） | 入金確認後即・初動アクション（ロードマップ送付など） |
| 🟢 **制作進行中** | プラン期間中・修正対応中 | 修正納品ごとに進捗更新 |
| 🟡 **FB待ち** | こちらがFBを返す番（要対応） | 期限内にFB送付 |
| 🟡 **顧客応答待ち** | 顧客のターン | 1〜2週間で動きがなければリマインド |
| ⚫ **完了** | プラン期間終了・継続なし | 1ヶ月後にリエンゲージ確認 |

## 3. 優先度（SLA）

| 優先度 | 条件 | レスポンスSLA |
|---|---|---|
| 🔴 **P0** | 成約済み／期限あり／約束済み | **24時間以内に動く**。期限のある約束は厳守 |
| 🟡 **P2** | 無料相談・有料化前段階 | 2〜3日以内に動く |
| ⚪ **P3** | 観察モード（離脱気味・休止） | 週1で点検すれば十分 |

> **絶対NG**：P0顧客への返信が48時間止まること。約束した期日を黙って過ぎること。

## 4. 顧客対応の標準フロー

### A. メッセージ受信時
1. 顧客ファイル（`customers/<id>.md`）を読む
2. これまでのFB記録・現在のステータスを確認
3. 返信案を作成（**テンプレ参照**＋顧客の特徴に合わせて調整）
4. 送信後、顧客ファイルの **`last_updated`** と **`next_action`** を更新

### B. 楽曲ファイル受信時
1. 顧客ファイルで、これまでの指摘点を確認
2. WAV分析→FBレポート作成（`templates/feedback-report.md` ベース）
3. 顧客ファイルに「これまでのFB記録」として要点を1〜2行追記
4. **次のFBの伏線を1つ用意してから返信**（段階的FBの①→②→③を意識）

### C. 入金確認時（Stripe）
1. **顧客ファイルのステータスを「成約済み」に更新**
2. 即日：ロードマップ・専用チャンネル招待など初動を完了
3. SCHEDULE.md に次回セッション枠を追加

## 7. ファイル更新規則

- **顧客ファイル**：やり取りのたびに `last_updated` と `next_action` を書き換える。FB記録は要点を1〜2行で追記
- **DASHBOARD.md**：ステータス・次のアクション・期限が変わったら同期
- **SCHEDULE.md**：期限のあるタスクが完了したらチェック、新しい期限が発生したら追加
- **log/YYYY-MM.md**：日々の応対サマリ（誰に・何を・結果）を追記

## 8. 危険サイン（早期発見リスト）

| サイン | 対応 |
|---|---|
| P0顧客から3日以上返信なし | こちらから軽く声をかける（プレッシャーにならない言い回し） |
| 修正回数が残り1回 | 仕上げの方向性を確認するメッセージを先回り |
| 指導期間終了2週間前 | 継続/アップセル提案のタイミング |
| 無料相談が1ヶ月続いている | 有料化シナリオを再設計 or リソース配分を下げる |
| ギガファイル便など期限付きデータ | 受領24時間以内に必ずDL＋ローカル保存 |

### ⚠️ 既存顧客への新LP案内時の注意（重要）

新LPを既存顧客（特に旧プラン特殊構成の契約者）に共有する際は、必ず以下の注意書きを添える：

```
※こちらのリンクから購入はしないようお願いします。
```

**理由**：
- LP上の購入ボタンから直接決済すると、新体系の単品プラン（¥9,800 / ¥19,800 / ¥98,000）になってしまう
- 既存顧客の特別構成（例：DAnさんの ¥29,600 = ¥19,800 + ビデオ面談 ¥9,800）が抜け落ちる事故が起きうる
- 一度購入されると返金処理 + 再決済の手間が発生し、信頼を損なう

**対象になる既存顧客**：
- DAIKIさん（旧週1コンサル＋ロードマップ＋3ヶ月 ¥29,600）
- 今後発生する旧プラン契約者すべて
- 旧プランの裏メニュー利用者全般

**運用ルール**：
- 新LPを既存顧客に紹介する目的は「商品体系のアナウンス」「内容の参考共有」「紹介依頼」のいずれか
- **絶対に「ここから買ってください」ではない**
- 既存顧客の決済は契約時の経路（旧Stripeリンク等）で完結させる

## 11. ジャンル別の対応方針（2026-05-19 追加）

トリケラテクノは **EDM / ダンスミュージック** が専門領域。
公式LP（roadmap-lp）でも「ロック・J-POP・K-POPを主軸にした制作には向いていません」と明記済み。
これに沿った運用ルールを以下に定める。

### ジャンル別の対応マトリクス

| ジャンル/楽曲タイプ | 対応スタンス | 商品提案 |
|---|---|---|
| **EDM / ダンスミュージック系**（House / Techno / Tech House / Trance / Future Bass / Big Room / Trap / DnB / Dubstep 等） | **本領域・フル対応** | 積極的に・ロードマップ案内OK |
| **ボカロ系・ダンス要素あり**（かいりきベア「ベノム」／Anyma風VOCALOID／電子音・打ち込み・ベース重視のボカロ） | **対応可能**：ダンスミュージック要素を引き寄せて指導 | 食いつき次第・ダンス寄りに引き寄せた上で |
| **ボカロ系・歌/メロディ/歌詞重視**（ヨルシカ／Orangestar／米津玄師系／ナユタン星人 等） | **会話はする・無理に続けない** | **向こうから具体的に食いつかない限り提案しない** |
| **JPOPロック / バンドロック系** | 同上（会話はする・無理に続けない） | 同上 |
| **K-POP / J-POP メインストリーム** | 同上 | 同上 |

### なぜ「ボカロ歌重視系・JPOPロック」は無理に続けないか

- **成約件数ゼロ**という実績データ（2026-05-19 時点）
- 専門外領域の深掘りには学習コストがかかる
- 専門領域（EDM/ダンス）の顧客に集中するほうが成約率が上がる
- 専門家のフリをして失敗するより、正直に限界を伝える方が信頼が残る

### 「食いつき」の判定基準（個別判断のブレ防止）

| 反応 | 判定 | 動き |
|---|---|---|
| 具体的な質問が返ってくる（操作・数値・プラグイン名など） | 食いついている | **続ける** |
| 試した結果を音源で送ってくる | 食いついている | **続ける** |
| 「もっと深く知りたい」「ロードマップ買いたい」 | 食いついている | **即対応・提案OK** |
| 「ありがとうございました」「検討します」のみ | 食いついていない | 1回フォローして終わり |
| 沈黙 2週間 | 食いついていない | **追跡しない** |
