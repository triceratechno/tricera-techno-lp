# ✅ CRM運用チェックリスト集

朝・夜・週次・月次の各タイミングで「これだけは絶対に通る」項目集。
忙しい時ほどここを開く。スキップしても自分を責めない、戻ってきた時に再開する。

---

## 🌅 朝のチェック（10分・毎日）

```
□ crm/index.html をブラウザで開く
□ 「今日のタスク」が何件かを確認
□ 🔴 P0タスクの締切を確認（特に約束済みのもの）
□ 顧客から新着メッセージ・通知が来ていないか確認
   □ LINE
   □ Discord
   □ メール
   □ Stripe（入金通知）
□ 今日中に動くべきタスクを最大3つに絞り込む
□ 顧客の名前と連絡手段の組み合わせを再確認（DAn / Dさんの混同チェック）
```

### 朝に絶対やらないこと
- 大量のFB制作にいきなり着手（午前は判断系、午後にFB系の頭の使い分け）
- 新規SNS投稿に時間を取られる前に、既存顧客の応対が終わっているか確認

---

## 🌙 夜のチェック（5分・毎日）

```
□ 今日対応した顧客のファイル last_updated を更新済みか
□ next_action が空の顧客がいないか
□ log/<月>.md に1行記録を追加（誰に何をして結果どうだったか）
□ 約束済みの期日タスクが残っていないか
□ 明日の最優先タスクを1つ決めて、SCHEDULE.md の頭に置く
```

### 夜に絶対やらないこと
- 顧客への返信を疲れた状態で書き始める（朝に回す）
- 「今日もっとやれたはず」と自分を責める（明日のエネルギーが減る）
- 飲酒後に重要な決定を顧客に伝える

---

## 📅 週次レビュー（毎週月曜・30分）

```
□ 先週の log/<月>.md を読み返す
□ 全顧客ファイルを順番に開いて、next_action と last_updated を確認
□ 1週間以上更新されていない P0顧客がいないか
   → いれば対応：ソフトリマインドか、状態整理
□ 今週の P0タスクを SCHEDULE.md にまとめる
□ 今週中にやる P2 を3つ以内に絞る
□ 期限切れ・対応漏れがないか SCHEDULE.md を上から点検
□ python crm/scripts/sync.py を実行して DASHBOARD / SCHEDULE / data-auto.js を最新化
□ 今週の「アップセル提案ウィンドウ」が来てる顧客がいないか確認
   → いれば対応文面を準備（送信は別の日でOK）
```

### 週次レビューで自問する3つ

1. **約束を守れた週か？** → 守れなかった案件があれば PLAYBOOK_EMERGENCY.md を確認
2. **危険サインが出ている顧客はいないか？** → PLAYBOOK の「危険サイン」を再読
3. **来週の最大の期日は何か？** → カレンダーに大きく印を付ける

## 📊 月次レビュー（毎月1日・60分）

```
□ 前月の log/<前月>.md を全部読み返す
□ 入金件数・成約件数を集計（KPI記録）
□ アップセル成功・失敗の振り返り
□ 新規顧客の数・流入経路の振り返り
□ 離脱・休止顧客の振り返り（理由パターンを抽出）
□ PLAYBOOK / templates / personas / 緊急対応マニュアル に追加すべきこと
□ log/<新月>.md を作成し、申し送り事項を冒頭に書く
□ プラン料金・コンテンツ価格の見直しが必要か検討
□ 全顧客ファイルの「これまでのFB記録」を読み返し、共通課題を抽出
   → 共通課題があれば note記事 / LP の改善ネタに
```

## 🔁 顧客対応のたびに通る最小チェック（30秒）

```
□ 連絡相手の本人を確定したか（DAn / Dさんの混同チェック）
□ 顧客ファイルを開いて状況を再確認したか
□ 返信内容が適切なテンプレを参照しているか
□ 押し売りトーンになっていないか
□ 送信後、顧客ファイルの last_updated と next_action を更新する予定か
```

---

## 🆘 何かおかしいと感じた時のチェック（緊急時）

```
□ 深呼吸して、即時返信したい衝動を抑える
□ PLAYBOOK_EMERGENCY.md を開く
□ 該当パターンがあるか確認
□ 24時間後の自分が後悔しない選択は何か自問
□ 必要なら一晩寝かせる（重大事項以外）
□ 対応後は必ず log/ に詳細記録
```

## 📌 このチェックリストの使い方

- 印刷して机の横に貼る、もしくは画面の隅にメモアプリで開いておく
- 全部できなくても気にしない、「通れたところ」をカウントする
- 1ヶ月使って合わない項目は削除・修正する
- このチェックリスト自体を月次レビューで見直す（メタ運用）
