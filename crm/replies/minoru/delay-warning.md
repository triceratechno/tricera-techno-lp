# Minoru｜途中経過・遅延予告テンプレ

## 用途
2026-05-09 14:55 に「本日中に納品」と約束した状況で、
**結果が出る前に**「夜遅くなりそう／日付変わるかも」と感じたら即送る予告メッセージ。

## なぜこれが重要か
- 約束した時間を **過ぎる前に** 連絡を入れる＝「言い訳の遅延」ではなく「予告した遅延」になる
- 信頼の落ち込み方が桁違いに違う
- 「黙って遅れる」が顧客対応で最悪のパターン
- PLAYBOOK_EMERGENCY.md §3 のセオリー

## 使用判断のタイミング目安
- **18時時点で半分しかできてない** → そろそろ予告検討
- **20時時点でドロップ部分が固まってない** → 確実に予告すべき
- **22時時点で完成見えない** → 最終予告（「明日早朝」or「明日中」を新提示）

## 📩 メッセージ案A：軽めの予告（深夜納品想定・本日中は守れる前提）

```
minoruさん、進捗のご連絡です🦖

集中して作業を進めているのですが、
仕上げに想定よりお時間をいただいており、

納品が **{時刻：23時頃／日付変わる前／深夜}** の見込みになりそうです。

本日中の納品はお約束通り守ります。
雑にしたくないので、もう少しだけ詰めさせてください。

お休み前に確認できなくても、
明日にゆっくり聴いていただいて大丈夫です🦕
```

## 📩 メッセージ案B：明日朝に伸ばすパターン（本日中は厳しいと判断）

```
minoruさん、すみません、進捗のご連絡です🦖

本日中にお渡しすると申し上げていた件、
仕上げに思った以上に時間がかかっており、

**明日（5/10）の朝までにお送りする** 形でもう少しお時間をいただけませんでしょうか。

雑な状態でお渡しするより、
Minoruさんが満足できるクオリティで仕上げてからお送りしたく、ご相談させてください。

何度もお待たせしてしまい本当に申し訳ありません。
内容で必ず取り返しますので、もう一晩だけお時間ください🦕
```

## 📩 メッセージ案C：致命的な遅れ（明日に伸ばすしかない・誠実な深い謝罪付き）

最終手段。これを使うのは「物理的に今日中は無理」と確信した時のみ。

```
minoruさん、本当に申し訳ありません🦖

「本日中にお渡しする」とお約束していた件、
仕上げが間に合わず、明日（5/10）まで時間をいただきたく、ご連絡しました。

何度もお待たせしてしまい、深くお詫びします。
言い訳になってしまうのですが、{簡潔な理由：構想していた配置と実際の音の馴染み方が想定と違い詰めに時間を要しているなど}。

明日（5/10）の **{具体時刻：午前中／14時まで／夕方まで}** には必ずお送りします。
新たに約束したこの期日は、今度こそ絶対に守ります。

待たせ続けてしまっていることに対して、
本当にすみません。

修正期間（〜5/17）の中で、
修正回数2回もしっかり活用できる形でお渡しできるよう、
最後まで雑にしないで仕上げます🦕
```

---

## 鉄則

- **「本日中にお渡しします」と約束した時間を1分でも過ぎる前に連絡**
- 「忙しくて」を理由にしない（顧客は自分の優先度の低さを感じる）
- 新しい期日を出したら、**今度こそ絶対に守る**（2連続の遅延は致命的）
- 内容を雑にして帳尻合わせ NG。むしろ普段以上に丁寧に仕上げる
