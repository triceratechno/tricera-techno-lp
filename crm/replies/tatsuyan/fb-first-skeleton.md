## 各セクションを埋めるための観察ポイント（聴く時のチェックリスト）

### 良い点を見つける（必ず2〜3個）
- [ ] ボーカルの音程・表情・録音の質
- [ ] ピアノの和声・タッチ・録音状態
- [ ] 曲構造（Verse / Pre-Hook / Hook の作り）
- [ ] 全体の感情の流れ

### 改善ポイントを見つける（1〜2個に絞る）
- [ ] ボーカルとピアノの帯域被り（200〜500Hz）
- [ ] サビでの音圧・ダイナミクス
- [ ] リバーブ・ディレイの量
- [ ] ステレオイメージ（広さ・分離）
- [ ] ボーカルのコンプ処理
- [ ] ビートが入る前提の空間設計（後で追加するスペースがあるか）

### 具体提案を作る（Ableton Live 12の機能を絡めて）
- EQ Eight / Utility / Glue Compressor / Vocoder など
- セッションビューでのアレンジ実験提案
