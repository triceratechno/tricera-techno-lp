# 💬 返信文ライブラリ

各顧客 × 主要シーンごとに、コピペ→微調整で送れる文面集。
すべて **トリケラテクノの文体（誠実・具体・「🦖」「🦕」を文末に・大人扱い）** に揃えてある。

## 使い方
1. 顧客フォルダを開く（`replies/<id>/`）
2. シーンに合うファイルを開く
3. {...} の波括弧部分を実情に合わせて差し替え
4. LINE/Discord/メールに貼り付けて送信

## 共通の文体ルール
- **絵文字**：🦖（始まり）／🦕（締め）。乱用しない、各メッセージ1〜2回まで
- **語尾**：「〜です」「〜ました」基調で、たまに「〜ね」「〜よ」を混ぜて温度を上げる
- **称賛は具体的に**：抽象的な「すごい」より「Drop/Hookの構造を意識できてる」
- **アドバイスは1つだけ**：情報過多にしない
- **問いかけで終わる**：次の返信を引き出す質問を最後に置く
