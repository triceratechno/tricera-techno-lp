# 雄太｜初回返信案

## 用途
LINE登録 → テンプレ返信受信後の **第一回返信**。
DTM歴1ヶ月の完全初心者向けに、トリケラテクノ流の確認済みパターン（構成要素＋展開＋参考曲を引き出す）で組み立てる。

## 設計意図
- **歓迎・称賛**：DTM歴1ヶ月で挑戦している姿勢を肯定
- **困りごと2つを統合**：「参考曲を分解して真似る」という1本軸に集約
- **構成要素＋展開**：トリケラテクノさんの確認済み定番フレーム
- **「楽器選び≠配置」の視点を提示**：雄太さんの「何の楽器を鳴らせば」の質問への根本回答
- **コード進行ベタ打ち問題**：参考曲のコード耳コピで一気に解消できることを伝える
- **参考曲を引き出す問いかけ**：次の対話の起点になる（やすさん向けと同じパターン）
- **ロードマップ案内なし**：信頼関係構築前なので絶対に出さない

## 📩 メッセージ案A（標準・推奨・LINE貼り付け用）

```
雄太さん、ご相談ありがとうございます。

DTM歴1ヶ月でEDM・エレクトロスウィングに挑戦されているの、いいですね。
ジャンルがしっかり決まっている時点で、最初のスタートとしては良い位置にいます。


ご相談いただいた2つのお悩み、

① コード進行がベタ打ちになる
② 楽器選びで盛り上げ・期待感を作れない

これ、実は両方とも本質は同じところにあります。


それは

「参考曲を分解して、真似することから始める」

ということです。


■ 楽曲は「要素」と「展開」でできている

ダンスミュージックは、ほぼ以下の組み合わせで出来ています：

・キック＆ベース：低域・土台
・ドラムス（ハイハットなど）：グルーブ
・メロディ（シンセ・リード）：楽曲の顔
・FX（ライザー・インパクト）：展開を知らせる
・アンビエンス（パッド）：世界観

そして展開はこう👇

イントロ → ビルドアップ → ドロップ → ブレイク → フック → ビルドアップ → ドロップ2 → アウトロ


「盛り上げる・期待感を出す」というのは、
楽器選びより 配置 の問題です。

・ライザーを入れる → 盛り上がりの予感
・ドロップ直前にドラムを止める → 期待感
・パッドを薄く重ねる → 世界観

このあたりが定番のテクニックです。


■ コード進行のベタ打ち問題

これも、参考曲のコードを耳コピして、まずそのまま使ってみる、
これで一気に解消できます。

DTMはゼロから組み立てるイメージがあると思いますが、
実は「真似すること」が一番の近道です。


■ 雄太さんに教えていただきたいこと

EDMとエレクトロスウィングの中で、

「こんな曲を作ってみたい」

という参考曲を1〜2曲教えていただけますか？

参考曲が分かれば、その曲をベースに、
雄太さんの楽曲制作にどう活かすか、もっと具体的にお伝えします。


引き続きよろしくお願いします！
```

- DTM歴1ヶ月の人にいきなりロードマップ案内は **絶対NG**
